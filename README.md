# Latte Latte

Sitio web de cafetería boutique para Latte Latte, hecho con React + TypeScript + Vite.

## Ejecutar

```bash
npm install
npm run dev
```

Luego abre la URL que muestre Vite.

## Personalización rápida

- `src/App.tsx`: textos, productos, precios, imágenes y secciones.
- `src/styles.css`: colores, tipografías, tamaños y responsive.
- `index.html`: SEO y metadatos.

Las imágenes de demostración usan Unsplash. Sustitúyelas por fotografías propias cuando las tengas.
